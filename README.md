# Калькулятор бюджету події (Event Budget Calculator)
* **Мета:** Зручний інструмент для швидкого планування витрат на заходи та розрахунку вартості на гостя в реальному часі.
* **Цільова аудиторія:** Організатори заходів, координатори, люди, що самостійно планують свята.
* **Структура:** Односторінковий застосунок (SPA) з категоріями витрат, повзунком непередбачуваних витрат та динамічним підсумком.
