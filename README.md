# Event Budget Calculator (Калькулятор бюджету події)

Вебдодаток для швидкого розрахунку приблизного бюджету дня народження, весілля, корпоративу чи іншої події.

**Live Demo:** https://yuraanime20909-art.github.io/event-budget/

## Можливості
- Вибір типу події: день народження, весілля, корпоратив, зустріч.
- Кількість гостей, витрати на їжу та напої на одну особу.
- Оренда локації, декор, розваги, інші витрати.
- Резервний фонд у відсотках.
- Миттєвий перерахунок основних витрат, резерву та загального бюджету під час введення.

## Технології
HTML5, CSS3, JavaScript (ES6+), без бібліотек.

## Запуск локально
Завантажте або клонуйте репозиторій і відкрийте `index.html` у браузері. Збірка не потрібна.

## Приклад розрахунку
20 гостей, їжа 500 ₴, напої 200 ₴, оренда 5000 ₴, декор 2000 ₴, розваги 3000 ₴, інше 1000 ₴, резерв 10% дають **27 500 ₴**.

## Структура
- `index.html` — розмітка, стилі та скрипт в одному файлі.
