# Event Budget Calculator (Калькулятор бюджету події)

Простий та зручний веб-додаток для планування та контролю фінансів будь-яких подій (днів народжень, весіль, корпоративів чи зустрічей).

## Особливості
- Додавання доходів та витрат.
- Автоматичний розрахунок загального балансу.
- Збереження даних у браузері (`localStorage`).
- Адаптивний та сучасний інтерфейс.

## Технології
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (ES6+)
